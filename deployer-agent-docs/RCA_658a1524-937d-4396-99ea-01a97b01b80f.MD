# Deploy RCA — iqfoam-business (initial deploy)

## Outcome
RECOVERED — app is LIVE at https://iqfoam-business.emergent.host (HTTP 200, serving the real Vite build).

## Original failure
- Run `ab4601e7-139c-4c4f-980b-da9ec830eab3` failed at **build_image**, frontend-build stage.
- `yarn install` aborted: `error html2canvas-pro@2.5.2: The engine "node" is incompatible with this module. Expected version ">=24.0.0". Got "22.23.1"`.
- Root cause: `html2canvas-pro@2.5.2` declares `engines.node >= 24`, but the frontend build image ships Node 22.23.1. yarn classic enforces the engines field and fails install.

## Fix applied (manifest)
- Added `--ignore-engines` to the frontend `yarn install` in both `Dockerfile.cloudbuild` (frontend-build stage, the file cloud build consumes) and `Dockerfile`.
- Rationale: html2canvas-pro is a browser-only rendering library; the Node >=24 floor is a yarn install-time precheck, not a runtime requirement. Vite bundles it on Node 22 without executing it in Node. Full manifest set (config.yaml + 5 template files) written to GCS; rebuild went green and promoted.
- Note for a cleaner long-term fix: E1 could pin `html2canvas-pro` to a version whose engines allow Node 22, removing the need for `--ignore-engines`.
